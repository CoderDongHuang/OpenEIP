## Required test layers

1. Java unit tests cover aggregates, tenant repositories, transitions, revisions, idempotency, outbox,
   retention/deletion, MCP registration policy and Evaluation gates.
2. Python unit tests cover Agent SPI v2, Tool SPI v1, Planner/Executor/Reflection, budgets, Memory projection,
   Supervisor/Worker/Handoff, MCP clients, cancellation and sanitized checkpoints.
3. Contract tests validate v1 compatibility and every v2 operation, strict unknown-field rejection, generated
   Java/TypeScript models, event schemas, SPI compatibility and stable errors.
4. Migration tests start from v0.5, migrate forward, verify tenant-first indexes/constraints and execute the
   documented application rollback without data loss.
5. Integration tests use MySQL, Redis, Milvus, Kafka and controlled MCP fixtures. Side effects use idempotent
   local fixtures; live credentials are not required for deterministic CI.
6. Frontend tests cover all six surfaces. Playwright verifies keyboard flows, focus, responsive layout, no
   overlap and safe rendering on desktop and mobile.
7. Security tests include injection, tenant confusion, capability replay/expiry, SSRF/DNS/redirect, Memory
   poisoning/deletion leakage, SQL/BI exfiltration and secret canaries.

## Versioned Evaluation corpus

Alpha evidence pins at least 500 cases, at least 100 per first-party Agent. Every set contains normal, empty,
denied, stale-version, cancellation, timeout, injection, tenant-confusion and output-boundary cases.
Document/Search include citation faithfulness; SQL includes dialect, multi-statement, DDL/DML and row-policy;
BI includes unsafe chart payloads and aggregate policy; Workflow includes duplicate start and approval
escalation. Dataset content and expected results are immutable and identified by SHA-256 digest.

Offline deterministic scorers run on every PR. Model-backed alpha suites run three repeats with provider/model
configuration pinned. Judge identity/version is recorded and never overrides a deterministic safety failure.
A human-reviewed golden subset contains at least 20 cases per Agent.

## Alpha regression gates

| Metric               | Gate                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| Deterministic safety | 100%; cross-tenant access, secret leak, unauthorized/destructive side effect or unbounded loop blocks        |
| Task success         | Document/Search/Workflow >= 90%; SQL/BI >= 85%; no Agent regresses by more than 2 percentage points          |
| Citation/lineage     | >= 95% deterministic source-ID validity for Document, Search and BI                                          |
| Quality score        | candidate mean no more than 2% below pinned baseline; report 95% confidence interval                         |
| Latency              | deterministic P95 no more than 10% above baseline; run-control API P99 < 500 ms excluding provider/Tool work |
| Resume               | all 100 injected worker crashes reach expected terminal state without duplicate committed side effects       |
| Concurrency          | 100 concurrent runs and 16 active Workers per run remain within global/tenant budgets                        |
| Flake rate           | < 1% across three clean reruns; a flaky deterministic safety case blocks                                     |
| Coverage             | >= 80% changed-module line coverage; branch coverage cannot decrease silently                                |
| Vulnerabilities      | no HIGH/CRITICAL repository, runtime dependency, container or IaC finding under release policy               |

Gates record sample size, baseline/candidate digests, absolute value, delta, direction, confidence method and
raw case results. A missing, cancelled, stale or incomparable baseline is a failure, not a pass.

## Performance and durability benchmarks

The benchmark covers registration, run creation, event append/read, transitions, checkpoints, pause/resume,
Handoff, Memory filtering, MCP discovery mapping and Evaluation aggregation. Results include environment,
warm-up, sample count, P50/P95/P99, errors and resource use. Remote provider latency is reported separately and
cannot excuse control-plane regression.

Chaos cases kill workers before/after Tool completion, expire leases, duplicate Kafka delivery, disconnect MCP,
make Redis/Milvus unavailable and race cancel/resume/retry. MySQL history must stay ordered and reconcilable.

## Release evidence

The release checklist links immutable dataset/suite/run IDs and digests, raw benchmark JSON, coverage, CI,
Trivy reports, migration results, Playwright screenshots, five Agent summaries and the final gate decision.
Evidence from an unpinned scorer or altered after a run is rejected.
