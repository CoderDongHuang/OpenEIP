# v0.7.0-alpha Release Checklist

> Status: Release preparation in progress | Version: `v0.7.0-alpha` | Candidate date: 2026-09-06

## Release Scope

Governance delivers server-derived tenant scope, default-membership provisioning, tenant isolation, tamper-evident
audit evidence, model and Prompt policy lifecycle, usage and budget views, runtime quota enforcement, trace
correlation, and the Governance management workspace described by Issue #99.

The alpha deliberately does not expose tenant creation/mutation or membership-administration writes. The migration
creates one default Governance tenant, and authenticated principals receive a server-owned membership on first
Governance access. Those deferred endpoints must not be inferred from the v0.7.0-alpha API contract.
