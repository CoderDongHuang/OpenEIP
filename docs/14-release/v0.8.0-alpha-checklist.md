## Release Scope

Marketplace introduces the tenant-scoped package catalog for Plugin, Connector, and Agent artifacts.
It records immutable version metadata and supports the `DRAFT -> REVIEWED -> PUBLISHED -> SUSPENDED`
lifecycle. Artifact bytes, download authorization, and signature verification remain external registry concerns.
