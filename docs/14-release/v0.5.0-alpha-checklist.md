## Release Scope

The Connector control plane delivers tenant-isolated CRUD and lifecycle operations, connection
testing, metadata extraction and versioned Connector SPI v1 contracts for all 16 adapters:
MySQL, PostgreSQL, Oracle, SAP, Redis, Kafka, GitHub, GitLab, Feishu, WeCom, Jira, Confluence,
MinIO, OSS, Email and Webhook. Credentials are accepted only by `secret://...` reference.
