# OpenEIP v0.9.0-alpha

## Scope

This alpha introduces a dependency-free, bounded HTTP GET benchmark for
repeatable OpenEIP performance evidence. It is a control-plane measurement
utility, not a production-capacity or high-availability certification.

## Highlights

- Explicit HTTP(S) target validation with private-network opt-in.
- DNS resolution pinning, redirect blocking, bounded response reads, request
  timeout, concurrency, warmup, and sample-count limits.
- P50, P95, and nearest-rank P99 latency, throughput, status, and transport
  outcome summaries in a versioned JSON contract.
- A deterministic loopback fixture, 25 focused contract tests, strict Ruff and
  Mypy gates, and 86% Performance module coverage.
- A versioned JSON Schema and synchronized CLI, SDD, test, security, quality,
  and release documentation.

## Compatibility

The release adds a CLI and versioned JSON evidence contract. It adds no REST,
SDK, Plugin SPI, event, database, migration, or frontend surface and changes no
existing runtime API behavior.

## Evidence Boundary

The recorded result uses a deterministic single-node loopback fixture. It does
not demonstrate production capacity, HA, autoscaling, chaos resilience,
multi-node recovery, authenticated workload behavior, or external provider
performance. Those claims remain out of scope for this alpha.
